Part 2 · Manual checks

Edit item from the public post menu (owner)
  1. Open your approved post, tap the 3 dots.
Expected: The "ویرایش پست" item is shown and links to /app/post/edit/<id>.
Edit item hidden for other sellers
  1. Open another seller's post, tap the 3 dots.
Expected: No edit item.
Edit item on the pending list
  1. Open pending/rejected posts, tap the 3 dots on a post.
Expected: The edit item is shown above delete and opens the edit page.
Edit page loads the saved post
  1. Open the edit link.
Expected: The caption is prefilled, and every image shows the full picture (not a thumbnail).
Delete disabled on the edit page
  1. Look at the delete button on the image.
Expected: It is disabled. Tapping it does nothing and sends no request.
Save is disabled for an empty caption
  1. Clear the caption.
Expected: ذخیره is disabled. Typing text enables it again.
Save updates the description
  1. Change the caption and press ذخیره.
Expected: A success toast shows, and the page redirects to the pending review page.
Saved post goes back to review
  1. After saving, open the pending list.
Expected: The post is listed as pending, and it is not in the public feed.
Lists refresh without reload
  1. After saving, check the feed, your profile, and the public post.
Expected: The new text shows (or the post is removed from public views), without a manual refresh.
Date shows the last update
  1. After saving, look at the post date on its card.
Expected: The date is today (updatedAt), not the original creation date.
Save failure keeps the text
  1. Turn off the network, change the caption, press ذخیره.
Expected: An error toast shows. The caption stays in the field.
Not-found for bad or foreign ids
  1. Open /app/post/edit/not-a-uuid, and a valid id that belongs to someone else.
Expected: The "پست مورد نظر وجود ندارد" page shows. There is no 500 error.
Signed-out visitor
  1. Sign out, then open an edit URL.
Expected: The page does not show post data. Note what actually happens.
New-post flow still works
  1. Open /app/posts/new, add images, write a caption, publish.
Expected: It works as before, and the edit state does not appear (delete works).
Layout at phone width and in dark mode
  1. Check the edit page at about 400px wide and in dark mode.
Expected: Text and buttons are readable. The page does not scroll sideways.
