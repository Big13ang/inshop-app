Edit post

A seller can open one of their posts from the 3-dots menu, change the caption, and save. The save sends the post back to review.

Built and tested Manual QA and one open backend item remain

What is built

  • Route /app/post/edit/[id]. Owner only, loaded with GET /seller/posts/:id, which returns the signed-in seller's post in any status except deleted.
  • Entry points: an "ویرایش پست" item in the public post 3-dots menu (owner only) and in the pending and rejected list menu.
  • Screen: the same details screen as the new-post flow. The header, the image slider, and the caption field are the shared components.
  • Images: full images, not thumbnails. Delete is disabled on this screen.
  • Save: PATCH /seller/posts/:id with the caption. On success it redirects to the pending page and refreshes every post view and the user profile.
  • Date: post cards show updatedAt.

Rules

  • Only verified sellers can call the owner route. Other sellers get 404 for posts that are not theirs.
  • A saved edit sends the post to pending review and hides it from the feed until an admin approves it.
  • Malformed ids return 404, not 500.
  • Saving is disabled while the caption is empty or a save is running.

Open items

  • Delete image needs a seller route to remove an image from a saved post. Until then the button stays disabled.
  • The edit page reuses the new-post header, so it reads "پست جدید".
  • Reorder is not on this screen.
